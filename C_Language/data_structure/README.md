# Data Structure Programs in C

Each `.c` file is a standalone example with its own `main` function. Compile and run one program at a time from the project root, for example:

```sh
gcc -std=c11 -Wall -Wextra C_Language/data_structure/Stack/stack_array.c -o stack_array
```

Then run the generated executable (`./stack_array` on Linux/macOS or `stack_array.exe` on Windows).

## Folders

- `Arrays`: insertion and deletion in a fixed-size array
- `Linked_List`: singly and doubly linked list operations
- `Stack`: array-based LIFO stack
- `Queue`: circular array-based FIFO queue
- `Trees`: binary search tree insertion, search, and traversal
- `Graphs`: adjacency matrix with breadth-first and depth-first traversal
- `Hash_Table`: integer hash table with linear probing and deletion
- `Searching`: binary search on a sorted array
